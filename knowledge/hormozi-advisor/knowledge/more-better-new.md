# More, Better, New — Putting It All Together
## a.k.a. "Core Four on Steroids"
## Source: acquisition.com Leads Course + $100M Leads — Putting It All Together

---

## What It Is

The meta-framework for scaling any advertising system. After you've set up the Core Four (warm outreach, content, cold outreach, paid ads), this is how you grow output without starting over.

Three questions, in order:
1. **More** — Can we do 10x more of what's already working?
2. **Better** — Can we improve each step in the funnel?
3. **New** — Do we need to add new placements, platforms, or methods?

---

## More — Volume First

The first question to ask on any working channel: "What's stopping us from doing 10x more of this?"

Almost always, the answer is nothing. The entrepreneur just never asked.

**The constraint exercise:**
Ask it directly. If you're sending 100 cold DMs a day, what stops you from sending 1,000? If you're spending $1K/day on ads, what stops you from spending $10K? The moment you identify the answer, that's your single constraint — and that's what you attack.

**Rule of 100 (baseline for getting started):**

| Method | Primary Action | Duration |
|---|---|---|
| Warm outreach | 100 reach-outs per day | 100 days in a row |
| Cold outreach | 100 reach-outs per day | 100 days in a row |
| Content | 100 minutes of content per day | 100 days in a row |
| Paid ads | $100/day in spend | 100 days in a row |

This is the floor, not the ceiling. The purpose: (1) you learn the value of a lead from doing the volume, (2) you build enough reps to teach and delegate it.

If you're not getting enough leads, you're not doing enough of the Core Four. It's always that simple.

## Better — Optimize the Funnel

Once volume is real, small percentage improvements compound fast. Getting better means more leads from the same effort — that's leverage.

**You only get better by testing.** One test per week, per platform. Four reasons to do it this way:

1. **Isolate the variable** — If you test multiple things at once, you never know what worked
2. **Avoid interference** — Simultaneous tests affect each other and corrupt the data
3. **Force prioritization** — Constrained to one test, you choose the one with the highest impact
4. **Enough runway** — Run it long enough to reach statistical significance (Google "statistical significance calculator")

**How to pick what to test — find the constraint:**

Map your funnel with actual percentages. Example:
- 30% opt-in rate
- 5% application rate
- 50% schedule rate

Add 5% absolute to each step. The step where +5% creates the largest percentage lift is your constraint. Attack that first.

In this example: opt-in 30→35% = +16% lift. Apply 5→10% = +100% lift. Schedule 50→55% = +10% lift. **Attack the apply step.**

**Prioritize front-to-back.**

The lowest-percentage steps happen at the front of the funnel (ad click-through, opt-in). The highest-percentage steps happen at the back (scheduling, closing). But front-end fixes have the largest absolute returns because everything downstream flows through them.

Spend 80% of your testing effort on: headline, hook (first 5 seconds), call-out, offer framing, landing page.

**Pro tip from the data:**
The top 0.1% of Facebook advertisers test 11x more creative than everyone else. You can't scale a mediocre ad profitably — the only way to find the exceptional ad is to make 11x more of them. More volume gets you better ads.

52 tests per year, one per week. Each one compounds. Gym Launch grew 40% in 18 months doing nothing new — just testing and improving each step of the existing funnel.

## New — Expand Only When Ready

"New" is the last resort, not the first move. Most businesses jump here too early.

**The market saturation myth:** You haven't saturated your market. You've saturated one method on one platform reaching one audience type. If any competitor can still get customers in your space, there's more attention available — you just haven't reached it yet.

**When to go new:** When incremental returns from more or better are lower than the effort of starting something new. Not before.

**Order of expansion — easiest to hardest:**

| Step | What It Means | Example |
|---|---|---|
| 1. New placement | Same platform, different spot | Running Instagram feed ads → add Stories |
| 2. New platform (same method) | Different platform, same media format | Short-form on TikTok → same content on Reels |
| 3. New platform (different method) | Different format and platform | YouTube long-form → Twitter text ads |
| 4. New core four method | Completely different acquisition type | Paid ads → building an outbound cold call team |

Each step up is higher risk, higher effort, longer ramp. Start with step 1. Extract everything. Then move to step 2.

Don't pendulum swing. A half-step that gets 80% of the upside beats a full pivot that breaks what's working.

---

## When to Flip the Order

**Under $1M annual profit: More → Better → New**
You don't have enough volume for percentage changes to move the needle. Just do more.

**Over $1M annual profit: Better → More → New**
At scale, a 5% improvement in a high-volume funnel is worth more than doubling a small one. Efficiency becomes the highest-leverage move.

---

## Summary

The full model:

```
1. MORE — Crank what works. Ask: what stops 10x? Attack the answer.
2. BETTER — Test one thing/week. Fix the constraint. Prioritize front-to-back.
3. NEW — Only when more/better returns diminish. Expand in order: placement → platform → method → core four.
```

Advertising is making known. The Core Four is how you do it alone. More/Better/New is how you scale it.

## Action Checklist

- [ ] For each active Core Four channel: ask "what would stop us from doing 10x?" — write down the answer
- [ ] Map your funnel with real percentages (opt-in, apply, schedule or equivalent)
- [ ] Identify the constraint step (highest impact from a fixed 5% absolute improvement)
- [ ] Set up one test this week on the constraint step — one variable only
- [ ] Use statistical significance calculator before calling a winner
- [ ] Are you at Rule of 100 baseline on at least one channel? If not, do that first
- [ ] Only consider "new" if more and better are genuinely maxed out
- [ ] If expanding: start with new placements on existing platforms, not new methods
