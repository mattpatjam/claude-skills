# Slash Command Definitions
## How to use these tools in Claude Code

---

## /offer [business or product description]

**What it does:** Builds a Grand Slam Offer for the specified product/service.

**Output format:**
1. Dream Outcome statement
2. Value Equation analysis (all 4 levers)
3. Core offer definition
4. Bonus stack (3-5 bonuses with objection each one kills)
5. Guarantee options (3 variants: aggressive / standard / conservative)
6. Scarcity/urgency mechanism
7. MAGIC name options (3 variants)
8. Price anchor recommendation

**Example:** `/offer Scalrize done-for-you LinkedIn content for event centers`

---

## /leads [channel + business]

**What it does:** Maps a lead generation strategy using the Core Four.

**Output format:**
1. Avatar definition (who exactly)
2. Where they live (platforms/channels)
3. Core Four breakdown: Warm Outreach / Cold Outreach / Content / Paid — which to prioritize and why
4. Lead magnet recommendation
5. First 30 days tactical action plan

**Example:** `/leads cold outreach for Bali Exception CRM targeting Jakarta RE agencies`

---

## /qualify [context: what product, what stage of lead]

**What it does:** Builds a WhatsApp or sales qualification sequence.

**Output format:**
1. Message 1 (the hook)
2. Message 2 (deepening question)
3. Message 3 (insight + positioning)
4. Message 4+ (logistics and budget framing)
5. Objection handling lines for the top 3 objections

**Example:** `/qualify inbound villa buyer inquiry, Canggu, came from Instagram`

---

## /scale [business]

**What it does:** Diagnoses the primary scaling constraint and prescribes the fix.

**Output format:**
1. Current stage (0-1M / 1-3M / 3-10M / 10M+)
2. Primary constraint identified
3. Top 3 growth levers to pull (in priority order)
4. What NOT to work on right now
5. Next 90-day focus

**Example:** `/scale Scalrize — have 2 clients, doing all work myself`

---

## /money [product + current pricing]

**What it does:** Audits your pricing model and surfaces money levers.

**Output format:**
1. Money model type (one-time / subscription / DFY / etc.)
2. Unit economics estimate (CAC, LTV, payback period)
3. Pricing ladder recommendation
4. 3 immediate ways to increase revenue without new clients
5. Pricing psychology tweaks

**Example:** `/money Bali Exception CRM — currently $150/month flat, 5 clients`

---

## /naming [offer description]

**What it does:** Generates product/service names using the MAGIC formula.

**Output format:**
- 5 name options with MAGIC breakdown for each
- Recommendation with rationale

**Example:** `/naming CRM for Indonesian real estate agencies`

---

## /guarantee [offer description + price point]

**What it does:** Designs a risk-reversal guarantee.

**Output format:**
- 3 guarantee options (aggressive / standard / soft)
- Language to use
- What to put in the fine print to protect yourself

**Example:** `/guarantee Scalrize DFY content at $2000/month`

---

## /market [niche or business idea]

**What it does:** Scores a market against Hormozi's selection criteria.

**Output format:**
- Pain level (1-10)
- Purchasing power (1-10)
- Targetability (1-10)
- Overall score + verdict
- Adjacent niches to consider

**Example:** `/market AI automation for Swiss event centers`
