## How to Add New Knowledge

When a new transcript arrives:

1. **Identify the topic** — Google Ads, SEO, email marketing, copywriting, etc. (not the speaker name)
2. **Check if a file already exists** for that topic → if yes, append; if no, create new
3. **Distill, don't transcribe** — extract frameworks, rules, and actionable principles only
4. **Note the source** in the file header and next to any source-specific insight
5. **Update this README** with the new file entry

## Naming Convention

`[topic].md` — lowercase, hyphenated

Examples: `google-ads.md`, `seo.md`, `email-marketing.md`, `copywriting.md`, `landing-pages.md`
