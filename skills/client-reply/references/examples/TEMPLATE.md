# Client Reply Examples — Continuous Improvement Log

This file logs examples of rewritten client messages along with their outcomes. Use this to identify patterns in what works best.

---

## Entry Template

Copy this template for each example:

```
### Example #[number] — [brief title, e.g., "Price objection in Seminyak listing"]

**Date:** [date rewrite was sent]

**Original incoming message:**
[Paste the original message from the client]

**Rewritten reply (what was sent):**
[Paste the rewritten message that was actually sent]

**Frameworks applied:**
- [Framework name]: [what was changed]
- [Framework name]: [what was changed]

**Context:**
[Brief context — who is the buyer, what stage of negotiation, what was the deal situation?]

**Outcome:** (optional, fill in later)
- Client response: [Did they reply? How fast?]
- Deal status: [Did they agree to viewing / offer / closing? Did price move?]
- Notable shift: [Any surprising reactions or new objections?]

**Rating:** (optional, 1-5)
- 1 = Didn't work, lost the deal
- 3 = Neutral, no change
- 5 = Worked great, moved the deal forward quickly

**Notes for improvement:**
[Any patterns you notice? What would you change next time?]
```

---

## How to use this

1. After you send a rewritten message via `/client-reply`, paste the original + rewritten versions here.
2. Note the frameworks used.
3. Check back in a few days/weeks and fill in the outcome section.
4. Periodically review entries to spot patterns (e.g., "Cialdini's scarcity frame always lands" or "Voss's mirroring technique takes longer to work").
5. Use these patterns to suggest prompt improvements.
